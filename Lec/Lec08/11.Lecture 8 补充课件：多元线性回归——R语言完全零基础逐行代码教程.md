## 阅读前先知道：这一讲到底在研究什么？

原课件用英国劳动力调查（LFS）数据探索**小时工资与性别之间的统计关联**，并且逐步在回归模型中加入受教育程度、零工时合同、全职或兼职、在现雇主处工作年限、工作合同类型、企业规模、婚姻状况、行业、职业等级、年龄及地区。

研究的问题可以用非常简单的中文表述：

> **男性与女性的平均小时工资是否不同？这种差异在把其他相关因素放入模型之后，还剩下多少？**

这并非 11 个彼此无关的练习：**每新增一个解释变量，就会得到一个新模型**。老师借此展示：由于遗漏了其他与工资有关的因素，最初仅包含性别的回归系数，可能与多变量控制后的系数不同。

请先记住三个词：

- **因变量（dependent variable）**：要解释的结果。这里为 `HOURPAY`（每小时工资，以英镑/小时为单位）。
- **主要自变量（key independent variable）**：最关注的解释因素。这里为 `SEX`（性别）；输出里最常读的是 `SEXFemale` 这一行。
- **控制变量（control variables）**：其他可能与工资有关、值得在模型中考虑的因素，例如 `AGE`、`HIQUL22D`。

课件分析的是**关联（association）**，而非通过这几段代码就证明性别、教育或婚姻状况对工资的因果影响。后文出现的“控制其他变量”指**统计条件比较**，不意味着我们随机分配了人们的性别、学历或工作。

## 第一章：第一次接触 R，也能看懂所有代码

### 1. R 和 RStudio 分别是什么？

- **R**：一种用于数据处理、统计计算与绘图的编程语言。
- **RStudio**：帮助你编辑、执行和管理 R 代码的软件界面。
- **脚本（script）**：以 `.R` 为扩展名的纯文本代码文件。
- **R Markdown（`.Rmd`）**：可将正文、代码、运行结果放在同一报告中的文件。
- **Console（控制台）**：RStudio 显示代码执行、输出与报错的区域。

在 RStudio 中，把代码输入脚本，再按 **Ctrl+Enter（Windows）/Cmd+Enter（Mac）** 可执行当前行或选中的代码。多行代码可一起选中运行。

### 2. 什么是数据框？`lfs` 是什么？

想象 Excel：每**行**是一个受访者，每**列**是一个变量（如工资、性别、年龄）。R 中储存这种数据的一种常见形式叫**数据框（data frame）**。

原课件所有模型都有 `data = lfs`，含义是：从已经加载到 R 的数据对象 `lfs` 中寻找变量。`lfs` 不是 R 的内置数据集，也不是一个函数。**原 HTML 课件没有提供创建 `lfs` 的完整数据清洗代码**，所以只复制回归语句到空白 RStudio 会遇到 `object 'lfs' not found`。

学习回归前，应先在自己的 R 工作环境中准备课程对应的 LFS 数据。为了检查数据是否读入成功，你可以使用以下**教学补充代码（非老师原始代码）**：

```r
# 查看对象是否存在
exists("lfs")

# 看前六行
head(lfs)

# 看数据结构、每列的数据类型
str(lfs)

# 看列名是否包含工资、性别等
names(lfs)

# 看数据的行数和列数
dim(lfs)
```

`#` 后是注释，不执行；`head()` 看前几行；`str()` 看结构；`names()` 看列名；`dim()` 返回“行数、列数”。

### 3. 为什么出现 `library()` 和 `%>%`？

`%>%` 是管道操作符，常由 `magrittr` 或 `dplyr` 提供：它把左侧结果传给右侧函数。比如 `x %>% summary()` 类似 `summary(x)`。

在原课件的 `lm(...) %>% summary` 中，意思是：

1. `lm(...)` 先拟合一个线性模型；
2. `%>%` 把这个模型传给 `summary`；
3. `summary` 打印模型结果。

原课件直接使用 `%>%`，**没有在这份 HTML 内展示载入程序包的命令**。若你的环境尚未启用该操作符，可使用以下**教学补充代码**：

```r
# 以下命令只在尚未安装时执行一次
install.packages("dplyr")

# 每次开启新的R会话后，需要使用时载入
library(dplyr)
```

也可以不使用管道，改写为 R 基础语法 `summary(lm(HOURPAY ~ SEX, data = lfs))`。这只是等价写法，**原课件代码仍在下文逐字保留**。

### 4. 符号逐个认识

| R 中写法 | 中文意思 | 在本课件里的作用 |
|---|---|---|
| `lm()` | linear model（线性模型）函数 | 拟合普通最小二乘线性回归（OLS） |
| `(` 和 `)` | 圆括号 | 放置传给函数的参数 |
| `,` | 逗号 | 分隔不同的函数参数 |
| `=` | 设置参数或赋值（视位置而定） | `data = lfs` 指定使用的数据 |
| `~` | 回归公式分隔符，读作“由……解释” | 左边是因变量，右边是解释变量 |
| `+` | 在公式右侧加入另一解释变量 | **不是把工资与性别数值相加** |
| `%>%` | 管道：把结果送入下一步 | 把模型送给 `summary` |
| `summary` | 摘要函数 | 在这里输出回归结果 |
| `SEXFemale` | R 回归输出中的一个系数名 | 女性相对于未展示参照类别（这里是男性）的差异 |
| `**` / `***` | 显著性标记 | **是输出表格的标记**，不是要键入的 R 代码 |

**初学者最常见的误会**：`HOURPAY ~ SEX + AGE` 的 `+` 并不是数学上 `SEX + AGE` 后去预测工资，而是告诉 `lm()` 同时放入两个解释变量。

### 5. 回归公式写成数学语言

第一段模型可以表示为：

\[HOURPAY_i = \beta_0 + \beta_1 Female_i + \varepsilon_i\]

`i` 代表第 `i` 个受访者；`Female_i` 是指示变量（女性为 1，男性为 0，采用本课件展示的分类编码）；`β₀` 是截距；`β₁` 是“女性相对男性的条件平均工资差异”；`εᵢ` 是模型未能解释的部分。

增加学历后的模型则写成：

\[HOURPAY_i = \beta_0 + \beta_1 Female_i + \sum_k\gamma_k Education_{ik} + \varepsilon_i\]

由于教育程度是分类变量，R 会为它的多个类别建立虚拟变量，**通常不需要手动为每种学历写一列 0/1**。每个系数的比较对象是“被省略的参照类别”。

## 第二章：怎样读懂任何一份 `lm()` 输出？

在接下来的 11 段结果里，控制台包含下列固定栏目。本章只需先理解基本含义，之后看实际数值会更容易。

### A. `Call:`——运行了什么模型

它将执行时的回归公式打印出来。例如 `lm(formula = HOURPAY ~ SEX, data = lfs)`，意味着工资是结果变量，性别是解释变量。

### B. `Residuals:`——残差的概况

**残差（residual）= 真实工资 − 模型预测工资**。

- `Min`：最小残差；`Max`：最大残差；
- `1Q`：下四分位数；`Median`：中位数；`3Q`：上四分位数。

比如某人真实小时工资 20 英镑、模型预测 18 英镑，残差就是 `20 − 18 = +2`；若预测 25 英镑，残差是 `20 − 25 = −5`。残差越大（按绝对值计），对该受访者预测得越不准。这里的五数概括**不能替代完整的残差诊断**。

### C. `Coefficients:`——最重要的系数表

| 原始表头 | 中文 | 该怎样理解 |
|---|---|---|
| `Estimate` | 估计系数 | 与参照组相比，工资水平相差多少（此处为英镑/小时）；连续变量则是每增加一单位对应多少差异 |
| `Std. Error` | 标准误 | 系数估计的不确定性，越小通常意味着越精确（还需结合估计值） |
| `t value` | t 统计量 | 通常是 `Estimate / Std. Error` |
| `Pr(>|t|)` | 双侧 t 检验的 p 值 | 在相应检验假设成立时，观察到如此或更极端 t 值的概率 |

`(Intercept)` 是截距：当所有连续解释变量等于 0、所有分类变量处于各自参照组时，模型预测的工资。**截距不一定对应现实中具有代表性的人**，尤其含有 `AGE` 时，年龄为 0 的情况不符合此处就业人群的实际含义。不要把所有模型的截距都直接解释为“普通男性的工资”。

### D. 显著性星号怎么读？

```text
***  p < 0.001
 **  p < 0.01
  *  p < 0.05
  .  p < 0.10（通常只称边缘证据，不等同于5%显著）
空白 p >= 0.10
```

常见课堂规则是 `p < 0.05` 时认为“在 5% 水平上统计显著”。但**统计显著不等于效应很大、不等于社会上一定重要，也不等于证明因果**；“不显著”也不能证明系数真实等于 0。

输出中的 `<2e-16`、`2.39e-13` 是科学计数法：`2e-16` 等于 `2 × 10⁻¹⁶`，不是“2乘以 e 减16”；这里的 `e` 表示十的幂次。

### E. `Multiple R-squared`、`Adjusted R-squared`

- **R²（决定系数）**：在样本内，模型解释的工资变异比例。`R² = 0.01748` 大约是 **1.748%**，并不是“性别决定了 1.748% 的工资”这种因果结论。
- **Adjusted R-squared（调整后的 R²）**：对解释变量的数量作惩罚修正，适合辅助比较复杂度不同的回归模型，但不是唯一优劣标准。
- 这里 11 个模型逐步加变量，普通 R² 在相同样本上通常不会下降，因为模型有更多自由度；因此**R² 增加本身不能证明新增变量具有因果意义或提高了样本外预测能力**。

### F. `Residual standard error` 与 `F-statistic`

- **Residual standard error（残差标准误）**：残差波动的典型规模。因工资以英镑/小时为单位，这里也以英镑/小时计。常被称为残差的标准差估计。
- **F-statistic（F 统计量）**：通常用来检验模型中（不含截距的）全部斜率系数是否同时为 0。它的 p 值很小时，说明至少有某些解释变量提供了统计信息；**这不意味着所有变量单独显著**。
- **degrees of freedom（自由度，DF）**：与样本量及估计的参数个数有关。比如第一个模型剩余自由度为 7345，含截距与性别两个参数，可推知该模型使用了 7347 条完整观测。

### G. 分类变量、参照组、虚拟变量

以第一个模型为例，输出只写 `SEXFemale`，没有单独一行 `SEXMale`，因为**男性是参照组**。若女性系数为 `−3.0591`，含义是：

> 女性平均小时工资比男性低 3.0591 英镑（在只控制性别的模型中）。

若加入学历而系数变为 `−3.6690`，则含义变为：

> 在控制学历后，女性相对男性的估计小时工资差异为 −3.6690 英镑。

这里的比较概念与“把女性工资降低 3.6690 英镑”完全不同：回归是描述样本关联，不是在修改数据。

### 模型 1｜只有性别：最简单的线性回归

**研究目标**：不加入其他控制因素，只比较男性与女性的平均小时工资。

**逐行（逐个组成部分）拆解**：

1. `lm(`：开始调用 R 内置的线性模型函数 `lm`；不是加载数据，也不是直接画图。
2. `HOURPAY ~ SEX`：公式左侧的 `HOURPAY` 是因变量；右侧的 `SEX` 是唯一自变量。
3. `data = lfs`：从 `lfs` 数据框里寻找这两个列名，而不是读取硬盘上名叫 lfs 的文件。
4. `)`：结束 `lm()` 参数列表并返回拟合好的模型对象。
5. `%>%`：把刚获得的模型继续传到下一步。
6. `summary`：打印模型摘要。它虽然没有显式写 `()`，在这段管道表达式中仍然作为函数调用。

**回归结果怎么一步一步读**：

- `(Intercept) = 22.4834`：男性（参照组）的**模型预测平均小时工资**为 £22.4834。
- `SEXFemale = −3.0591`：女性比男性平均少 £3.0591/小时。
- **由两者计算女性预测均值**：`22.4834 − 3.0591 = 19.4243` 英镑/小时。这是按这份样本与模型计算的预测均值，不是全英国女性工资的固定数字。
- `Std. Error`：性别系数标准误 `0.2676`，代表估计存在抽样不确定性。
- `t value = −11.43`、`p < 2e−16`、`***`：在通常假设下，性别系数显著不为 0。
- `R² = 0.01748`：仅凭性别，模型解释了工资样本变异约 **1.75%**。因此“统计上显著”和“解释程度很高”不是一回事。
- `Residual standard error = 11.44`：预测误差仍有较大波动（英镑/小时）。

**一个能帮助理解的日常类比**：这像是把所有受访者仅分成“男性”“女性”两组，用这两个组各自的平均工资预测组内每个人。组内的人仍然差异很大，因此 R² 可以很低。

**常见错误**：`lm(SEX ~ HOURPAY, data = lfs)` 把因变量和自变量颠倒了，研究问题会完全不同；`lm(HOURPAY + SEX, data = lfs)` 缺少公式的 `~`；缺少 `lfs` 数据时不能运行。

### 模型 2｜加入教育水平 `HIQUL22D`

**与模型 1 相比多出了什么？** 在 `SEX` 后面加入 `+ HIQUL22D`，让不同学历成为控制变量。

**代码每部分的具体含义**：`HOURPAY ~ SEX + HIQUL22D` 表示同时使用性别和学历来解释工资；`HIQUL22D` 是一整列教育类别，**不要求新手手动制作五个新变量**。R 对分类因子建立对应的虚拟变量；`data = lfs` 仍指同一个数据框；`%>% summary` 仍打印结果。

**这个模型必须掌握“参照组”**：老师在 HTML 中明确指出：`SEX` 的参照类别是 **Male（男性）**，`HIQUL22D` 的参照类别是 **Degree（学位）**。因此：

- `(Intercept) = 27.1162`：男性且学历是 Degree 的预测平均小时工资为 £27.1162（没有其他解释变量）。
- `SEXFemale = −3.6690`：**在学历水平相同时**，女性比男性估计少 £3.6690/小时。
- `HIQUL22DNo Qualification = −11.7713`：不具备资格证书者相对于 Degree 学历，工资估计低 £11.7713/小时（比较时保持性别相同）。
- `HIQUL22DHigher education = −5.5659`：此教育类别相对 Degree 较低 £5.5659/小时；不是相对于“不具备资格证书”低这么多。
- `HIQUL22DA level or equivalent = −7.9860`、`HIQUL22DGCSE A*-C or equivalent = −9.0507`：也都**相对于 Degree**；不能把这些系数直接相加比较不同学历。

**把公式变成具体数字**：

- Degree 男性：`27.1162`。
- Degree 女性：`27.1162 − 3.6690 = 23.4472`。
- 无资格男性：`27.1162 − 11.7713 = 15.3449`。
- 无资格女性：`27.1162 − 3.6690 − 11.7713 = 11.6759`。

这四个数字是 **该加性模型给出的预测值**，不是个体工资保证值。由于公式没有 `SEX:HIQUL22D` 交互项，模型还**假定女性与男性的工资差异在所有学历类别中相同**；这是建模形式的假设，并没有在这里单独检验。

**与第一段比较**：女性相对男性的估计差异由 `−3.0591` 变成 `−3.6690`，绝对值反而增加。老师指出一种可能解释：男女学历构成不同，而控制学历后未调整的工资差异被重新分解。**这不能单凭回归系数就严格证明“女性比男性学历高”**；要验证样本学历构成仍需做描述性统计。`R² = 0.1543`，模型解释工资变异约 **15.43%**，明显高于第一段。

**易错理解**：不能说“女性降薪 3.669 英镑”；不能说“学历解释了性别工资差异的 15.43%”。R² 指**全模型解释的总体工资变异比例**。

### 模型 6｜加入企业规模 `MPNR02`

**变量含义**：课件将 `MPNR02` 用作 **size of the firm（企业规模）** 的指标。输出中有许多按照员工数量分组的类别。

- `MPNR0211-19 = −1.11462`，`p = 0.035319`：该组与参照类别相比，小时工资估计低约 £1.11，在 5% 水平显著。

### 模型 7｜加入婚姻状况 `MARSTA`

**新增变量**：`MARSTA` 是婚姻或伴侣关系类别。讲义中列出了 `Married, living with spouse`、`Married separated from spouse`、`Divorced`、`Widowed`、`Currently or previously in civil partnership` 等水平。

### 模型 8｜加入行业 `INDE07M`

**新增内容**：`INDE07M` 是工作所属行业（industry）。这是课堂展示性别系数显著变化的关键一步。

**代码操作**：在原公式末尾再添加 `+ INDE07M`，R 会产生行业类别相对于行业参照组的多行系数；无需写循环，也无需自己对每个行业调用一次 `lm()`。请留意**一行公式可以很长，不代表它是 12 个不同的模型**。

**新增行业系数的例子**：

- `INDE07MEnergy and water = +4.42746`，`p = 0.020668`。
- `INDE07MConstruction = +4.48751`，`p = 0.013705`。
- `INDE07MTransport and communication = +4.96552`，`p = 0.005238`。
- `INDE07MBanking and finance = +4.19420`，`p = 0.017189`。
- `INDE07MPublic admin, education and health = −0.39858`，`p = 0.820134`，不显著。

这些都是**相对被省略的行业参照组**的差异。原课件没有在正文明确给出该基准组的名称，因此需要用因子水平检查，不能擅自为参照组命名。

**最重要的变化是性别项**：

- 模型 7 的女性系数约 `−3.0069`；
- 模型 8 的女性系数变为 `−2.12838`；
- 即当进一步把行业类别纳入模型后，男女条件工资差异的**绝对值**下降约 `0.88` 英镑/小时。

老师据此讨论：行业之间存在工资差异，一些男性占比较高的行业可能薪酬较高，行业构成可能解释一部分原始工资差异。严格而言，**本课件没有通过性别×行业交叉表或因果分析证明这一机制**；它展示的是加入行业后的系数变化。

`R² = 0.2602`：样本工资变异解释比例提高至 **26.02%**。这仍不等于“行业独自解释了26.02%”。

**常见疑问**：“行业有的系数显著、有的却不显著，是否说明整个变量没用？”不一定；单个类别与基准组的 t 检验，不等同于对**整个行业变量**的联合 F 检验。若希望检验整组因素，需要额外模型比较；这**不属于本讲原始代码**。

### 模型 9｜加入职业等级 `NSECMJ20`

**新增变量**：`NSECMJ20` 是社会经济职业类别或职业等级，讲义正文称为 **seniority（职位层级/职业等级）**。结果里能看到高层管理与专业岗位（参照类别）、低层管理与专业岗位、中间层职业、常规职业等多种类别。

- `NSECMJ20Intermediate occupations = −10.73648`：估计少 £10.74/小时。
- `NSECMJ20Routine occupations = −12.62290`：估计少 **£12.62/小时**。

### 模型 10｜加入年龄 `AGE`

**新增变量**：`AGE`（年龄）。注意与前面的分类变量不同，讲义中它直接作为**连续数值变量**参与回归。

**这是语法上很重要的区别**：`AGE` 是一个量化数值，输出通常就叫 `AGE`，只有**一行系数**，而不是 `AGE18-25`、`AGE26-35` 等多个类别行（除非数据预先分组或 R 中把年龄转成因子）。

**读懂关键输出**：

- `AGE = 1.071e−01` 等于 **0.1071**，可四舍五入为 **£0.11/小时/岁**。
- 更完整的表达是：在控制其余已经纳入的因素后，年龄每增加 1 岁，模型估计小时工资平均增加约 **£0.1071**。
- 如果只按线性模型关系推算，年龄差 10 岁时，工资差约 `10 × 0.1071 = 1.071` 英镑/小时（其他变量都固定），但**这不意味着任何人连续工作十年工资必然增长这个数**。
- `SEXFemale = −1.753e+00` 等于 **−1.753**，即约 **−£1.75/小时**。
- `R² = 0.3765`：总体解释约 **37.65%**。

**为什么有 `e+00`？** 这是科学计数法：

- `2.274e+01 = 22.74`；
- `−1.753e+00 = −1.753`；
- `1.071e−01 = 0.1071`；
- `−3.772e−05 = −0.00003772`。

R 在系数表较长时统一用科学记数法缩短打印长度。并不是回归算法换了，也不是单位换了。

**潜在模型限制**：当前模型将年龄与工资的关系假定为**线性**。现实中不同年龄段可能有复杂工资轨迹。若要考虑二次项、分段回归等，需要另外建模；原 HTML 这里没有做这些检查。年龄还可能与职业工龄相关，但二者含义不同。

**第一个问题：为什么 `SEXFemale` 一开始是 −3.06，第二次反而到 −3.67？**

## 第五章：使用真正的零基础思维，理解回归过程中的 10 个问题

### 问题 1：为什么“加一个变量”却多出好多行系数？

因为这个新变量可能是**分类变量**，R 会自动转换为多个虚拟变量。比如 `HIQUL22D` 有多个学历类别，输出会为所有**非参照类别**列出系数，而不是只有 1 个学历总系数。

### 问题 2：为什么参照类别不出现在系数表里？

这是避免包含截距时所有类别虚拟变量完全共线的一种常用编码方式。参照类别的效应被吸收到截距里。选择不同参照类别会改变各类别系数的显示方式，但不改变模型对同一观测的拟合值。

### 问题 3：`SEXFemale` 是什么意思？

它不是要在代码里使用的新变量名，而是 R 在**结果表里拼接因子变量名与类别标签**形成的系数名称。`SEXFemale` 表示女性相对于性别的参照组男性的条件差异。

### 问题 4：`+` 与 `%>%` 有什么本质区别？

公式里的 `+` 是**声明多个预测变量**。`%>%` 是**把已经计算出的对象传给下一步函数**。例如 `lm(HOURPAY ~ SEX + AGE, data = lfs) %>% summary` 中，这两个符号分别负责模型结构和代码执行流程。

### 问题 5：负的系数代表“坏”吗？

不是。负号表示在该模型的比较方式下，被比较组的预测数值较低；它本身不表示道德评价，也不自动证明因果或统计显著。

### 问题 6：为什么 `p < 0.05` 不是“该理论有95%的概率是真的”？

p 值是在给定统计检验的零假设和其他假设下，衡量观察到如此或更极端数据的概率。它不是零假设为真或为假的后验概率，也不是结果可重复的保证。

### 问题 7：多个系数都为负，是不是应该加起来？

仅当你希望预测**同一个人**且这些系数分别对应此人的真实属性时，可以把截距与相关的类别差值及连续变量项按公式相加。**不能把同一个分类变量下所有互斥类别（所有学历或所有地区）同时加上去**，因为一个人通常只能属于其中一个类别。

### 问题 8：为什么年龄系数 0.107 而教育是 −11.77？

年龄系数的单位是“每增加 1 岁”；教育系数的单位是“所属教育类别相对参照学历”。数值大小不在同一比较尺度上，不能直接说“教育影响是年龄的 110 倍”。

### 问题 9：R² 只有 0.389，是不是模型失败？

不是。社会科学中的个人工资由许多未测量或难以建模的因素共同决定，R² 不必等于 1。是否足够好取决于研究目标、理论、识别策略、预测要求和诊断。课件也明确指出，还有大部分工资变异没有被模型解释。

### 问题 10：这 11 段代码能不能直接用于自己的 NHTS 行程研究？

不能原封不动复制 `HOURPAY`、`SEX`、`HIQUL22D` 等变量名，因为它们属于 LFS 工资示例。**可以迁移思路，不可迁移变量**：先建立一元基准模型，再逐步增加相关人口学与家庭特征作为控制，比较主要解释变量的系数、R²、标准误和模型诊断，同时审查数据结构、抽样设计以及观测间的独立性。

- `model1` 只是自拟对象名称，并不是课程数据中的列。
- `summary(model1)` 与直接 `lm(...) %>% summary` 在模型输入相同时有同样的摘要结果。

### 练习 B：看分类变量有哪些水平

```r
# 先看变量本身的储存类型
str(lfs$HIQUL22D)

# 如果该变量是因子，显示因子水平
levels(lfs$HIQUL22D)

# 查看某个类别的人数（包含缺失项计数）
table(lfs$HIQUL22D, useNA = "ifany")

# 如属于factor，可查看对比编码
contrasts(lfs$HIQUL22D)
```

`$` 的用法：`lfs$HIQUL22D` 意味着从 `lfs` 里取出 `HIQUL22D` 这列。`levels()` 适用于因子；若返回 `NULL`，请先用 `str()` 判断类型，不要随意把数值编码强行转换后直接回归。

### 练习 C：分别保存最简单和更完整的模型

```r
model1 <- lm(HOURPAY ~ SEX, data = lfs)
model2 <- lm(HOURPAY ~ SEX + HIQUL22D, data = lfs)

summary(model1)
summary(model2)

# 只取出估计系数
coef(model1)
coef(model2)
```

`coef()` 返回系数向量，适合看模型参数；`summary()` 返回详细的拟合诊断统计和回归系数的推断结果。

### 练习 D：从模型对象里提取 R²

```r
summary(model1)$r.squared
summary(model2)$r.squared
```

`summary(model1)` 的返回值包含多个命名元素；`$r.squared` 访问其中的 R²。

### 练习 E：查看最终模型的预测值与残差

```r
final_model <- lm(
  HOURPAY ~ SEX + HIQUL22D + FLEX22W6 + FTPT +
    EMPLEN + JOBTYP + MPNR02 + MARSTA + INDE07M +
    NSECMJ20 + AGE + GOR9D,
  data = lfs
)

# 提取各观测的模型拟合值
head(fitted(final_model))

# 提取各观测的残差
head(residuals(final_model))

# 画基础残差-拟合值图，供初步检查
plot(final_model, which = 1)
```

注意：完整诊断不能只看一张图；还应根据课程后续章节理解函数形式、异方差、高杠杆值、影响点、共线性和抽样设计等问题。`which = 1` 是指定显示第 1 种诊断图，不是说只绘制 1 个数据点。

## 第七章：初学者最常见的报错及处理方法

| 你可能看到的错误或困惑 | 主要原因 | 应怎样检查 |
|---|---|---|
| `object 'lfs' not found` | 没有创建/读取 `lfs` 对象 | 先运行数据读取步骤，再试 `exists("lfs")` |
| `could not find function "%>%"` | 未载入提供管道的包 | 执行 `library(dplyr)`，或使用 `summary(lm(...))` |
| `object 'HOURPAY' not found` | 数据列名拼错，或传入数据框不对 | 用 `names(lfs)` 与 `str(lfs)` 检查 |
| `0 (non-NA) cases` | 有效样本不足或相关变量全是缺失 | 检查缺失值、数据筛选与变量编码 |
| `contrasts can be applied only to factors with 2 or more levels` | 某分类变量在当前拟合样本只剩一种类别 | 检查筛选条件、因子水平和缺失 |
| `NA/NaN/Inf in 'y'` 等 | 目标变量含非法或无限值 | 检查 `HOURPAY` 的类型和异常编码 |
| 模型系数出现 `NA` | 设计矩阵秩不足、完全共线或冗余类别 | 检查变量间的关系、编码和因子水平 |
| 输出里出现 `e+01` | 科学计数法 | 按 `×10^指数` 还原，不表示代码执行错误 |
| 控制台中长系数表被分成两块 | 控制台宽度较窄，打印自动换行 | 按同一行名的顺序对应阅读，必要时加宽 Console |
| `SEXFemale` 不存在于 `names(lfs)` | 系数名并非原始列名 | 原始数据列是 `SEX`；结果表组合形成系数名称 |

**对调查数据的额外提示**：LFS 原始数据可能包含“拒绝回答”“不适用”“不知道”等特殊编码。课件 HTML 只展示已准备好的 `lfs` 数据上的回归，不提供从原始调查文件到该对象的完整清洗步骤。不要仅凭本教程就假定原始数据可以直接 `lm()`；先核对数据字典和教师的预处理要求。

### 练习 1：解释单变量回归

### 练习 6：比较模型

**参考答案**：不可以。变的是**模型估计的条件差异**，不是任何个人的实际工资。两项相差约 1.277 英镑/小时，只能说在纳入这些控制变量后性别相关系数绝对值变小了。

### 练习 7：关于地区工资

**参考答案**：不能。这是名义小时工资的条件差异；尚未比较地区物价、生活成本或其他福利。

## 第九章：函数与术语速查

| 写法 / 名称 | 中文名称 | 本讲主要作用 |
|---|---|---|
| `lm()` | 线性回归函数 | 根据工资与解释变量估计 OLS 回归 |
| `summary()` | 摘要函数 | 打印系数表、残差、拟合指标 |
| `%>%` | 管道操作符 | 将模型结果送给 `summary` |
| `data = lfs` | 指定数据来源 | 让公式中的变量从 `lfs` 查找 |
| `~` | 回归公式分隔符 | 左为因变量、右为解释变量 |
| `+` | 添加自变量 | 在公式中纳入更多解释变量 |
| `coef()` | 提取估计系数 | 查看截距与各变量系数 |
| `fitted()` | 拟合值 | 查看模型对各样本的预测 |
| `residuals()` | 残差 | 真实值减拟合值 |
| `str()` | 结构检查 | 看列的类型与数据形式 |
| `names()` | 列名查看 | 核对工资、学历等列是否存在 |
| `levels()` | 因子水平 | 识别分类变量的类别 |
| `contrasts()` | 因子对比编码 | 查看类别如何相对参照组编码 |
| `table()` | 频数表 | 查看各类别人数 |
| `Estimate` | 系数估计值 | 方向及差异大小 |
| `Std. Error` | 标准误 | 系数估计的不确定性 |
| `Pr(>|t|)` | 双侧 t 检验 p 值 | 单个参数的统计显著性 |
| `Multiple R-squared` | 决定系数 R² | 样本内工资变异解释比例 |
| `Adjusted R-squared` | 调整后的 R² | 对参数数量作修正的拟合指标 |
| `Residual standard error` | 残差标准误 | 估计残差波动尺度 |
| `F-statistic` | F 统计量 | 通常检验非截距系数联合为 0 |
