## 一、运行前的准备

### 1. 本讲研究什么？

本讲使用英国季度劳动力调查（January–March 2025）的 `lfs` 数据，主要观察 `HOURPAY`（小时工资）的分布，还尝试使用 `SEX`（类别编码）进行分组。重点不在回归，而在**用图形正确理解连续数值的分布**：集中于哪里、是否右偏、极端值会怎样影响图形、如何比较不同组。

### 2. 从零开始运行

```r
# 如果尚未安装，再运行一次
install.packages(c("readr", "dplyr", "ggplot2"))

# 每次开启新的 R 会话都需要加载
library(readr)
library(dplyr)
library(ggplot2)

# 文件与脚本在同一个工作目录时，可使用以下文件名
lfs <- read_tsv("lfsp_jm25_eul_pwt24.tab", show_col_types = FALSE)

# 确认读取成功，以及研究变量存在
dim(lfs)
names(lfs)
str(lfs[c("HOURPAY", "SEX")])
summary(lfs$HOURPAY)
table(lfs$SEX, useNA = "ifany")
```

`install.packages()` 负责把工具安装到电脑；`library()` 负责在当前会话中启用；`read_tsv()` 读取TAB分隔文件；`<-` 是赋值（把右侧结果保存为左侧对象）。如果文件不在当前工作目录，需要提供正确路径。`names()` 显示列名；`str()` 显示列类型；`summary()` 看概况。

**数据质量警告：** `HOURPAY` 可能包含 `NA`、不适用记录或特殊缺失编码。正式作图前需要对照 LFS 数据字典清洗。以下首先原样解释课堂代码，后文提供更稳妥的教学版写法。图中的频数和密度默认也**没有应用调查权重**，不能直接视为英国总体工资分布。

## 二、零基础必会语法

| 写法 | 名称 | 在这堂课的意思 |
|---|---|---|
| `lfs` | 数据框对象 | 类似一张表格 |
| `HOURPAY` | 列名 | 小时工资字段 |
| `SEX` | 列名 | 性别分类编码（需查字典） |
| `lfs$HOURPAY` | `$` 提取 | 取出数据框中的一整列 |
| `f(x)` | 函数调用 | 用括号把参数交给函数 `f` |
| `x = 10` | 命名参数 | 指定某项参数的值 |
| `"text"` | 字符串 | 文字需用英文引号括起来 |
| `%>%` | 管道 | 左边结果输入右边函数 |
| `+` | ggplot加图层 | 把几何对象、标签、主题加到图上 |
| `<` | 比较运算符 | 小于，如 `HOURPAY < 70` |
| `-HOURPAY` | 降序排序简写 | 在 `arrange()` 中按大到小排序 |
| `c(0,70)` | 向量 | 组合两个值用于设定范围 |
| `aes()` | aesthetic mappings | 将数据列映射到横轴、颜色等视觉属性 |
| `fill` | 填充 | 图形内部颜色；不是轮廓线颜色 `colour` |
| `alpha` | 透明度 | 0全透明，1不透明 |

### `%>%` 与 `+` 的区别（本讲最重要语法）

```r
lfs %>% filter(HOURPAY < 70) %>% ggplot(aes(HOURPAY)) + geom_histogram()
```

从左到右：**数据表** `lfs` → **筛选行** `filter()` → **建立绘图对象** `ggplot()` → **添加直方图层** `geom_histogram()`。`%>%` 主要连接数据处理步骤；`+` 主要连接 ggplot 的绘图图层。新手不能把这两类符号随意互换。

### 变量映射和常量样式的差别

```r
geom_density(fill = "blue")     # 无论数据是什么，全部固定为蓝色
geom_density(aes(fill = SEX)) # 由 SEX 每条记录的取值决定填充
```

前者是**常量**，后者是**映射**；这一区别贯穿后半讲。

## 三、全部17段原文代码逐段讲解

### 01. 绘制第一张小时工资直方图

**课堂原始代码：**

```r
lfs %>% ggplot(aes(HOURPAY)) + geom_histogram()
```

**逐项解释：** `lfs` 是数据框；`%>%` 是管道，表示把左边的数据交给右边的绘图函数。`ggplot(aes(HOURPAY))` 建立图形对象，`aes()` 告诉 ggplot 将 `HOURPAY` 映射到横轴。`+ geom_histogram()` 增加直方图这一图层。每根柱表示一段工资范围，柱高表示落入该范围的记录数。没有指定 `binwidth` 时，ggplot2 会默认使用30个箱，并出现提示；这不是运行错误。


**看到信息 `stat_bin() using bins = 30. Pick better value binwidth.` 怎么办？** 这只是ggplot2提示它选择了30箱。可以按第3节明确箱宽，不代表程序失败。

### 02. 添加标题、横轴、纵轴和数据来源

**课堂原始代码：**

```r
lfs %>% ggplot(aes(HOURPAY)) + 
  geom_histogram() +
  labs( title = "Distribution of hourly wage",
        x = "Hourly wage (£)",
        y = "Count",
        caption = "Source: Quarterly Labour Force Survey - January-March 2025")
```

**逐项解释：** `labs()` 专门添加或修改文字标签。`title` 是总标题，`x` 是横轴标题，`y` 是纵轴标题，`caption` 是图下方的来源说明。`=` 把函数参数和参数值对应起来；英文内容放在双引号里属于文本字符串。`geom_histogram()` 的绘图逻辑没有改变，只是图的注释更完整。

### 03. 手动设置直方图箱宽为10

**课堂原始代码：**

```r
lfs %>% ggplot(aes(HOURPAY)) + 
  geom_histogram(binwidth = 10) +
  labs( title = "Distribution of hourly wage",
        x = "Hourly wage (£)",
        y = "Count",
        caption = "Source: Quarterly Labour Force Survey - January-March 2025")
```

**逐项解释：** `geom_histogram(binwidth = 10)` 将箱宽设为10个工资单位：每个柱覆盖约£10的区间。箱宽越大越平滑、细节越少；箱宽越小越容易暴露细节和随机波动。`binwidth` 是单个区间的宽度，不是柱子数量，也不是工资截断值。实际分箱起点由ggplot2算法决定，并不一定恰好是0、10、20。

### 04. 将图表主题改为深色

**课堂原始代码：**

```r
lfs %>% ggplot(aes(HOURPAY)) + 
  geom_histogram() +
  labs( title = "Distribution of hourly wage",
        x = "Hourly wage (£)",
        y = "Count",
        caption = "Source: Quarterly Labour Force Survey - January-March 2025") +
  theme_dark()
```

**逐项解释：** `theme_dark()` 控制图的视觉主题，如背景、网格线和文字对比；它不会改变数据、分箱或统计结论。`+` 是向 ggplot 对象添加图层/配置，与管道 `%>%` 不同。主题还可以改为 `theme_minimal()`、`theme_classic()` 等。

### 05. 找出小时工资最高的10条记录

**课堂原始代码：**

```r
lfs %>% arrange(-HOURPAY) %>% select(HOURPAY) %>% head(n=10)
```

**逐项解释：** `arrange(-HOURPAY)` 按 `HOURPAY` 从大到小排序，前面的负号在此表示降序；`select(HOURPAY)` 只保留工资列；`head(n=10)` 只显示前10行。整个过程是数据筛选与查看，不是画图。原讲义的输出显示最大的十个数值从98.8递减到91.4；它们是数据集中的记录，不要直接解释为总体最高工资。`arrange(desc(HOURPAY))` 是更易读的替代写法。


**讲义实际控制台输出：**


`A tibble: 10 × 1` 指10行1列；`<dbl>` 表示双精度数字类型；最左边的1至10是行号，并不是工资值。

### 06. 筛选小时工资低于70英镑的数据后画图

**课堂原始代码：**

```r
lfs %>% filter(HOURPAY<70) %>%
   ggplot(aes(HOURPAY)) + 
  geom_histogram() +
  labs( title = "Distribution of hourly wage",
        subtitle = "Sample of people earning less than £70 per hour",
        x = "Hourly wage (£)",
        y = "Count",
        caption = "Source: Quarterly Labour Force Survey - January-March 2025") +
  theme_minimal()
```

**逐项解释：** `filter(HOURPAY < 70)` 只保留工资小于70的记录（不包括等于70）；再交给 `ggplot()` 绘图，因此**统计样本本身变化了**。`subtitle` 是副标题；`theme_minimal()` 采用简洁主题。`<` 是“小于”的比较符号，写成 `<=` 则包含70。数据中 `NA` 也不会满足这个筛选条件。

### 07. 不删数据，仅把视图限制到0–70

**课堂原始代码：**

```r
lfs %>%
   ggplot(aes(HOURPAY)) + 
  geom_histogram() +
  labs( title = "Distribution of hourly wage",
        subtitle = "Sample of people earning less than £70 per hour",
        x = "Hourly wage (£)",
        y = "Count",
        caption = "Source: Quarterly Labour Force Survey - January-March 2025") +
  theme_minimal() +
  coord_cartesian(xlim = c(0,70))
```

**逐项解释：** `coord_cartesian(xlim = c(0,70))` 将横轴**可视范围**限制为0到70，但通常不会删除原始观测，和上一段 `filter()` 不同。`xlim` 意为x轴限制，`c(0,70)` 创建含两个端点的向量。这里原讲义副标题仍写“样本工资低于£70”，严格说不准确，因为只是缩放图形视图，并非筛选样本；推荐改成“View focused on £0–£70”。

### 08. 将横轴改为以10为底的对数刻度

**课堂原始代码：**

```r
lfs %>%
   ggplot(aes(HOURPAY)) + 
  geom_histogram() +
  labs( title = "Distribution of hourly wage",
        subtitle = "Logarithmic scale",
        x = "Hourly wage (£)",
        y = "Count",
        caption = "Source: Quarterly Labour Force Survey - January-March 2025") +
  theme_minimal() +
  scale_x_log10()
```

**逐项解释：** `scale_x_log10()` 把横轴变成以10为底的对数刻度，适合非常右偏、跨度很大的正数分布。横轴上等距移动表示**倍数变化**，不再是固定英镑差额。零和负数无法取普通实数的log10，ggplot可能丢弃这些值并报警告；先检查工资非正数及特殊编码是否被处理。它与 `log10(HOURPAY)` 作为新数据列有关联，但不是完全一样的作图设置。

### 09. 把直方图改成核密度图

**课堂原始代码：**

```r
lfs %>%
   ggplot(aes(HOURPAY)) + 
  geom_density() +
  labs( title = "Distribution of hourly wage",
        subtitle = "Logarithmic scale",
        x = "Hourly wage (£)",
        y = "Density",
        caption = "Source: Quarterly Labour Force Survey - January-March 2025") +
  theme_minimal() +
  scale_x_log10()
```

**逐项解释：** `geom_density()` 绘制核密度估计（KDE）曲线，将直方图式的区间频数概括成平滑的分布形状。纵轴写 `Density` 而不是 `Count`，因为曲线高度不是人数。这里通过 `scale_x_log10()` 在对数变换后的x轴上计算/展示分布；对照绝对英镑坐标解释曲线时尤其谨慎。密度平滑程度受带宽控制，不能把每个局部波峰都当作真实人群结构。

### 10. 给密度图增加地毯图

```r
lfs %>%
```

```r
lfs %>%
```

### 12. 用SEX变量分组填充密度曲线

**课堂原始代码：**

```r
lfs %>%
   ggplot(aes(HOURPAY)) + 
  geom_density(aes(fill=SEX)) +
  labs( title = "Distribution of hourly wage by sex",
        subtitle = "Logarithmic scale",
        x = "Hourly wage (£)",
        y = "Density",
        caption = "Source: Quarterly Labour Force Survey - January-March 2025") +
  theme_minimal() +
  scale_x_log10() +
  geom_rug()
```

**逐项解释：** `geom_density(aes(fill=SEX))` 将填充映射到数据里的 `SEX` 列，意图按照类别区分多条分布曲线。**关键限制：**如果 `SEX` 是数值型（例如1、2），ggplot可能按连续数值处理，甚至不会自动建立你期待的离散组。稳妥写法是 `aes(fill = factor(SEX), group = factor(SEX))`，并根据官方数据字典将编码映射成人类可读标签。原始代码应先运行检查结果，不要默认它已正确按性别分组。


**教学版对照（补充，并非原讲义代码）：**

```r
# 先把类别编码转换为离散分组
lfs %>%
  filter(!is.na(HOURPAY), HOURPAY > 0, !is.na(SEX)) %>%
  ggplot(aes(x = HOURPAY, fill = factor(SEX), group = factor(SEX))) +
  geom_density(alpha = 0.25) +
  scale_x_log10()
```

`factor(SEX)` 将数值编码当作**类别**，不是连续测量；但1、2分别是什么仍须用官方数据字典核对。这段只处理R的 `NA`，不自动识别调查问卷中的特殊负数编码。

### 13. 使用alpha透明度降低重叠遮挡

**课堂原始代码：**

```r
lfs %>%
   ggplot(aes(HOURPAY)) + 
  geom_density(aes(fill=SEX), alpha=0.2) +
  labs( title = "Distribution of hourly wage by sex",
        subtitle = "Logarithmic scale",
        x = "Hourly wage (£)",
        y = "Density",
        caption = "Source: Quarterly Labour Force Survey - January-March 2025") +
  theme_minimal() +
  scale_x_log10() +
  geom_rug()
```

**逐项解释：** `alpha=0.2` 是透明度设置：0为完全透明，1为完全不透明，0.2为比较透明。按不同类别填充的密度区域发生重叠时，更容易同时观察两组。它只改变显示效果，不影响统计数据，也不是显著性水平0.2。

## 四、讲义输出怎么读

### 1. 提示信息不等于报错

讲义绘制直方图时出现的 `stat_bin() using bins = 30. Pick better value binwidth.` 是分箱提示：不指定箱宽时，ggplot2选择30箱作为默认值。

### 2. 最高工资列表

前述第5段代码返回10×1的tibble及对应工资值。它说明数据中工资列的较高取值，不说明这些人的身份，也不代表已经加权的总体分位数。

### 3. 比较三种不同的图

- 直方图：横轴是工资区间，纵轴 `Count` 是该区间观测数。
- 密度图：纵轴 `Density` 是经过平滑的密度估计，不是人数。
- 地毯图：坐标轴附近的短线表示各条观测的位置；样本大时会重叠。

### 4. 为什么绘图前必须看数据？

原讲义通过 `arrange(-HOURPAY)` 先查极值，再用 `filter()`、`coord_cartesian()` 或 `scale_x_log10()` 处理长尾。这个逻辑很重要：**先诊断分布，再选展示方式，不要为了图好看随意删极端值。**

## 五、常见错误与修复

| 报错或现象 | 可能原因 | 建议处理 |
|---|---|---|
| `could not find function "ggplot"` | 未加载ggplot2 | `library(ggplot2)` |
| `could not find function "%>%"` | 未加载dplyr/magrittr | `library(dplyr)` |
| `object 'lfs' not found` | 尚未读取数据或对象名不一致 | 先运行 `lfs <- read_tsv(...)` |
| `object 'HOURPAY' not found` | 列名不匹配 | `names(lfs)` 检查拼写和大小写 |
| `unexpected end of input` | 少了括号/引号，或最后多了 `+` | 检查代码尾部和括号配对 |
| `log-10 transformation introduced infinite values` | 工资含零或无效非正数 | 核查编码并筛选有效正数 |
| `Removed ... rows containing non-finite...` | 缺失值、非有限值或刻度不可表示 | 查清具体行的缺失原因，不要直接忽略 |
| 分组图只有一条曲线 | SEX是数值型、未转分类或分组不明确 | 检查 `str(lfs$SEX)`，使用 `factor(SEX)` |
| 标签都显示1、2而不是文字 | 编码还没解码 | 对照官方变量字典转换标签 |
| 图中柱宽和预期不同 | 未设置 `binwidth` 或箱起点不同 | 显式设 `binwidth`，必要时检查 `boundary` |
| 缩放后柱高没变 | 使用 `coord_cartesian()` 只缩放视图 | 与 `filter()` 区别理解 |

### 三种“处理高工资”的方法不一样

```r
# 方法A：删去高于或等于70的观测后计算直方图
lfs %>% filter(HOURPAY < 70) %>% ggplot(aes(HOURPAY)) + geom_histogram()

# 方法B：保留样本，仅缩放显示范围
lfs %>% ggplot(aes(HOURPAY)) + geom_histogram() + coord_cartesian(xlim = c(0, 70))

# 方法C：显示对数横轴，便于看清较大数值跨度
lfs %>% filter(HOURPAY > 0) %>% ggplot(aes(HOURPAY)) + geom_histogram() + scale_x_log10()
```

**请注意：**A改变统计样本；B主要改变观看范围；C改变坐标尺度并可能排除无法取对数的非正值。不能把三张图当作同一种处理。

## 六、配套练习及答案

**练习1：** 不修改其他绘图参数，让直方图每个箱宽5英镑。

```r
lfs %>% ggplot(aes(HOURPAY)) + geom_histogram(binwidth = 5)
```

**练习2：** 添加副标题和来源说明。

```r
lfs %>% ggplot(aes(HOURPAY)) +
  geom_histogram() +
  labs(subtitle = "Hourly pay distribution", caption = "Source: LFS 2025 Q1")
```

**练习3：** 只查看工资大于零且小于50的记录。

```r
lfs %>% filter(HOURPAY > 0, HOURPAY < 50) %>% ggplot(aes(HOURPAY)) + geom_histogram()
```

**练习4：** 使用对数横轴并画带地毯线的密度图。

```r
lfs %>% filter(HOURPAY > 0) %>%
  ggplot(aes(HOURPAY)) +
  geom_density() + scale_x_log10() + geom_rug()
```

**练习5（思考）：** 为什么 `aes(fill = SEX)` 比 `fill = "blue"` 更复杂？

答：前者依赖数据列的类型、取值、分组规则、图例；后者只是固定视觉样式。对于数值型类别编码，通常需先转成 `factor`，并确保分类含义正确。
