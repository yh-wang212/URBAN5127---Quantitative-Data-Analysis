### 1.5 这几类对象是什么？
- **向量（vector）**：一列同类型值，常由`c(...)`生成。
- **数据框（data.frame / tibble）**：像Excel表格，行对应观测、列对应变量。
- **函数（function）**：执行特定任务，如`mean()`求平均、`lm()`拟合回归。
- **参数（argument）**：括号里告诉函数如何工作的选项，例如`data = lfs`。
- **模型对象**：`lm(...)`运行后返回的结果，里面有系数、残差、拟合值等，不只是一个单独数字。
- **因子（factor）**：R记录分类变量的特殊类型，参照组决定类别回归系数的解释方式。

### 代码 01｜计算男性与女性的平均小时工资

**原讲义位置**：男性与女性的平均工资。

**这段想做什么？**

先按照SEX划分组别，再对每组HOURPAY求均值，保留两位小数，以便在后面讨论抽样差异。

**课堂原始R代码（完整保留）**

```r
lfs %>% group_by(SEX) %>% 
  summarise(mean_wage = mean(HOURPAY) %>% round(2)) %>% 
  knitr::kable()
```

**逐行讲解**

1. **第1行** `lfs %>% group_by(SEX) %>%`：从`lfs`数据框开始进入管道流程。 出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `group_by(SEX)`按性别分组，影响后续汇总函数。
2. **第2行** `summarise(mean_wage = mean(HOURPAY) %>% round(2)) %>%`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `summarise()`输出每组的统计汇总。 `mean(HOURPAY)`计算小时工资的算术平均数。 `round(2)`代表保留2位小数，而非取第2个值。
3. **第3行** `knitr::kable()`：`knitr::kable()`用于生成展示用表格；`::`指定来自knitr包。

**把函数和统计概念拆开看**

1. `group_by(SEX)`不会立即计算任何统计量，而是告诉后续`dplyr`函数“接下来按性别分别处理”。
2. `summarise(mean_wage = ...)`每组生成一个名为`mean_wage`的结果；左边是自己起的列名。
3. `mean(HOURPAY) %>% round(2)`先算平均工资，再把得到的数字交给`round(2)`，其中2表示保留两位小数。
4. `knitr::kable()`把汇总数据渲染为适合HTML/Markdown展示的表格。

**课件输出怎样读？**

该段输出可能作为HTML表格或图形展示，不一定显示为控制台打印。关注对象在下一步代码中是如何被使用的。

**初学者容易踩的坑／研究上的注意事项**

这里的组均值属于**描述统计**：它描述样本，并不能单靠两个均值不同就推出总体具有统计显著的差异。若工资含NA，应根据数据清洗规则处理，而不是直接使用`na.rm=TRUE`而不记录缺失情况。

### 代码 02｜用正态分布计算极端Z值的右尾概率

**原讲义位置**：使用R获取概率。

**这段想做什么？**

课程给出标准化统计量11.26，展示R如何计算“标准正态值达到或超过11.26”的概率。

**课堂原始R代码（完整保留）**

```r
1-pnorm(11.26)
```

**逐行讲解**

1. **第1行** `1-pnorm(11.26)`：`pnorm()`返回累计正态分布概率；左侧的`1-`将左尾转为右尾。

**把函数和统计概念拆开看**

1. `pnorm(z)`返回标准正态分布中“随机变量不大于z”的累计概率。
2. `1 - pnorm(11.26)`用1减去左侧累计概率，得到理论上的右尾概率。
3. 课件输出`[1] 0`是数值精度下的显示结果，并不表示数学上的概率严格等于零。
4. 如果进行**双侧**检验，通常还要同时考虑另一侧的极端区域，不能将这一行直接当作双侧p值。

**课件输出怎样读？**

下面是从**原HTML控制台输出中摘取的关键行**（不是重新计算的结果；完整输出仍在原课件）：

```text

```

出现`[1] 0`说明R打印了第一个数值元素为0；极小右尾概率在此算法下可能因浮点数舍入显示为0，不代表概率数学上严格等于零。

**初学者容易踩的坑／研究上的注意事项**

对极端尾部概率，教学补充的更稳健写法是`pnorm(11.26, lower.tail = FALSE)`；这能避免`1 - pnorm(...)`因舍入产生0。双侧正态尾部概率示例可写为`2 * pnorm(abs(11.26), lower.tail = FALSE)`，但这并不替代课件实际使用的Welch t检验。

### 代码 03｜对性别分组进行Welch双样本t检验

**原讲义位置**：检验不同性别的工资差异。

**这段想做什么？**

通过原始数据检验两组的总体平均小时工资是否有差异，而不仅观察样本均值。

**课堂原始R代码（完整保留）**

```r
t.test(HOURPAY ~ SEX, data=lfs)
```

**逐行讲解**

1. **第1行** `t.test(HOURPAY ~ SEX, data=lfs)`：`data=lfs`明确指定从lfs表取变量。 `~`连接分析公式两侧；这一段说明了结果变量和解释变量/分组变量之间的关系。 `t.test()`检验性别两组工资的总体均值差，默认是Welch版本。

**把函数和统计概念拆开看**

1. `t.test()`在这里因公式右侧是两组分类变量而执行两样本t检验。
2. `HOURPAY ~ SEX`可读为“用性别分组比较小时工资”；波浪线左边是被比较的数值变量，右边是分组变量。
3. `data=lfs`说明变量都到lfs数据框中寻找。
4. R默认使用Welch两样本t检验，允许两组方差不同；这和经典等方差t检验的自由度与标准误可能不同。

## 三、按课堂顺序串起来：这一讲完整分析流程

### 一步一步理解“抽样—估计—检验”
1. **总体**是想描述的所有对象；**样本**是实际拿到的数据。数据只覆盖样本，因此相同研究重复抽样可能得到不同均值。
2. **描述性差异**：比如样本里男性均值22.48，女性均值19.42，差3.06。这个数字只是本次样本的结果。
3. **零假设H₀**：在总体中两组均值相同，差为0；**备择假设H₁**：两组总体均值不同（双侧）。
4. **检验统计量**衡量观察到的差异相对于抽样不确定性有多大；t值/Z值越极端，通常越不支持H₀。
5. **p值**是假定H₀成立时，出现至少同样极端数据的概率；它不是“结论错误的概率”，更不是效应大小。
6. **95%置信区间**通过重复抽样方法构建，其覆盖总体参数的长期比例约95%；不是“参数有95%的随机概率落入本次固定区间”。
7. **重要前提**：LFS可能有复杂抽样、权重及缺失编码；课堂`mean/t.test/lm`演示标准方法，但正式研究需决定是否使用调查设计。

### 需要记住的完整逻辑

1. 先**分组描述样本均值**，观察实际差异。
2. 再**假设总体无差异**，理解抽样波动可能造成什么样的样本差距。
3. 用概率和**Welch t检验**评估这种差异的统计证据。
4. 把两组均值改写为**线性回归+虚拟变量**，学会比较系数、标准误与p值。

## 六、初学者常见错误与排查顺序

1. **object not found（对象不存在）**：确认是否先创建了`lfs`或`fake_data`，或前一步的`select()`是否把变量删掉。
2. **could not find function（找不到函数）**：确认是否安装并`library()`了相应包。
3. **unexpected symbol / unexpected end of input（语法错误）**：检查括号、引号、逗号和前一行末尾的`%>%`是否完整。
4. **missing values / NA / -Inf**：统计函数遇到`NA`或`log(0)`会出问题，正式分析需遵循数据字典及清洗记录。
5. **contrasts can be applied only to factors with 2 or more levels**：筛选样本后某个分类变量可能只剩一类，需要检查`table()`或`levels()`。
6. **课程输出与自己不同**：先比较数据版本、样本行数、变量类型、参考组、缺失处理和包版本，不要立即修改统计模型去“凑数”。
7. **统计显著误当成因果关系**：观察数据中的关联仍可能受未观测因素影响，报告必须诚实描述限制。
