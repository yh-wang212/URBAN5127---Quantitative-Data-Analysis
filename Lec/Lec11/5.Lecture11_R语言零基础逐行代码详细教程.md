### 1.2 把R代码当成一句完整的话来阅读

| 写法 | 初学者的读法 | 常见误解 |

### 1.5 这几类对象是什么？
- **向量（vector）**：一列同类型值，常由`c(...)`生成。
- **数据框（data.frame / tibble）**：像Excel表格，行对应观测、列对应变量。
- **函数（function）**：执行特定任务，如`mean()`求平均、`lm()`拟合回归。
- **参数（argument）**：括号里告诉函数如何工作的选项，例如`data = lfs`。
- **模型对象**：`lm(...)`运行后返回的结果，里面有系数、残差、拟合值等，不只是一个单独数字。
- **因子（factor）**：R记录分类变量的特殊类型，参照组决定类别回归系数的解释方式。

### 代码 02｜用lm.cluster按家庭进行聚类稳健回归

**原讲义位置**：估计模型。

**这段想做什么？**

对log工资拟合多元模型，同时允许同一家庭内的回归误差彼此相关。

**课堂原始R代码（完整保留）**

```r
lfs %>%
  mutate(log_wage = log(HOURPAY)) %>%
  lm.cluster(data = ., 
             log_wage ~ SEX + AGE + HIQUL22D + FTPT + JOBTYP + MPNR02 + new_MARSTA + INDE07M + NSECMJ20 + GOR9D, 
             cluster = "HSERIALP") %>%
  summary()
```

**逐行讲解**

1. **第1行** `lfs %>%`：从`lfs`数据框开始进入管道流程。 出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。
2. **第2行** `mutate(log_wage = log(HOURPAY)) %>%`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `mutate()`创建新数据列或覆盖现有列。 `log()`默认取自然对数；必须注意输入是否为0或负数。
3. **第3行** `lm.cluster(data = .,`：`data=.`中的`.`是管道传来的数据，**不是小数点或缺失值**。 `lm.cluster()`估计按指定群组聚类的回归与稳健标准误。
4. **第4行** `log_wage ~ SEX + AGE + HIQUL22D + FTPT + JOBTYP + MPNR02 + new_MARSTA + INDE07M + NSECMJ20 + GOR9D,`：`~`连接分析公式两侧；这一段说明了结果变量和解释变量/分组变量之间的关系。 公式中的`+`表示**同时纳入**这些解释变量，并非对列做逐行算术加法。 `new_MARSTA`是前面重编码后的婚姻状况，执行前要确认它已存在。
5. **第5行** `cluster = "HSERIALP") %>%`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `cluster = "HSERIALP"`按家庭标识归组；同户观测允许相关。
6. **第6行** `summary()`：`summary()`输出摘要；模型对象包括估计系数、标准误、t值、p值等。

**把函数和统计概念拆开看**

1. `lfs %>% mutate(log_wage = log(HOURPAY))`建立本次建模的对数因变量。
2. `lm.cluster()`来自`miceadds`包，按指定聚类变量计算回归估计与相应标准误。
3. `data = .`把左侧数据传递给函数。
4. `cluster = "HSERIALP"`告诉函数按照名为HSERIALP的家庭标识聚类。
5. `summary()`展示模型结果；稳健标准误的基本思想是允许户内相关、要求不同家庭间满足相应独立条件。

## 三、按课堂顺序串起来：这一讲完整分析流程

### 为什么“同一个家庭的人”不应被当成完全独立？
设A、B是同一个家庭的两名成员，他们可能共享住房环境、收入压力、所在地理区域，导致工资方程遗漏因素的残差相关。如果我们假设所有个体互相独立，传统标准误可能低估真实不确定性。

- **聚类单位**：HSERIALP代表家庭，属于同一家庭的观测赋予相同聚类标识。
- **聚类稳健标准误**：允许簇内观测在一定条件下相关，而不同簇之间满足独立性假设。
- **没有聚合**：仍然保留个人层面的每一行数据，不等于先计算每户平均工资。
- **不是万能补救**：聚类标准误不修复遗漏变量、函数形式错误、内生性，聚类簇数过少也有推断挑战。
- **课堂依赖**：本讲紧接着第10讲的数据选择和变量创建，不能把单独代码块当作从空白R环境可直接运行的完整脚本。

### 需要记住的完整逻辑

1. 确保家庭标识HSERIALP存在，而且重编码变量没有在前一步被删掉。
2. 以个人为观测单位拟合对数工资模型。
3. 指定按家庭聚类，允许簇内误差相关。
4. 读懂聚类稳健标准误与默认OLS标准误的区别。

## 六、初学者常见错误与排查顺序

1. **object not found（对象不存在）**：确认是否先创建了`lfs`或`fake_data`，或前一步的`select()`是否把变量删掉。
2. **could not find function（找不到函数）**：确认是否安装并`library()`了相应包。
3. **unexpected symbol / unexpected end of input（语法错误）**：检查括号、引号、逗号和前一行末尾的`%>%`是否完整。
4. **missing values / NA / -Inf**：统计函数遇到`NA`或`log(0)`会出问题，正式分析需遵循数据字典及清洗记录。
5. **contrasts can be applied only to factors with 2 or more levels**：筛选样本后某个分类变量可能只剩一类，需要检查`table()`或`levels()`。
6. **课程输出与自己不同**：先比较数据版本、样本行数、变量类型、参考组、缺失处理和包版本，不要立即修改统计模型去“凑数”。
7. **统计显著误当成因果关系**：观察数据中的关联仍可能受未观测因素影响，报告必须诚实描述限制。
