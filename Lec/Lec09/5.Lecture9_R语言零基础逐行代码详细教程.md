### 1.2 把R代码当成一句完整的话来阅读

| 写法 | 初学者的读法 | 常见误解 |
|---|---|---|
| `x <- ...` | 把右边结果保存到x | 以为`<-`是小于号 |
| `f(x, y)` | 调用函数f，把x和y作为参数 | 以为所有括号都在做数学乘法 |
| `data = lfs` | 指定数据对象 | 以为这里是把变量赋值给lfs |
| `df$AGE` | 从df里抽取AGE这一列 | 以为`$`有货币意义 |
| `a %>% b()` | 先做a，再把结果交给b | 与ggplot的图层加号`+`混淆 |
| `y ~ x1 + x2` | 用x1、x2共同解释y | 把公式中的`+`当成数值求和 |
| `"Female"` | 这是**字符串文字** | 误以为是变量名 |
| `TRUE`与`FALSE` | 布尔值/逻辑值 | 与文字`"TRUE"`混淆 |
| `# ...` | 注释，对运行结果无影响 | 把注释当成一定会运行的代码 |
| `<`、`==` | 分别表示小于、是否相等 | 把`==`与赋值符混淆 |

如果一行很长，先找最外层函数，再拆成“传入的数据→做了什么→返回什么”；碰到多层括号，从**最里面的函数**开始理解。

### 1.5 这几类对象是什么？
- **向量（vector）**：一列同类型值，常由`c(...)`生成。
- **数据框（data.frame / tibble）**：像Excel表格，行对应观测、列对应变量。
- **函数（function）**：执行特定任务，如`mean()`求平均、`lm()`拟合回归。
- **参数（argument）**：括号里告诉函数如何工作的选项，例如`data = lfs`。
- **模型对象**：`lm(...)`运行后返回的结果，里面有系数、残差、拟合值等，不只是一个单独数字。
- **因子（factor）**：R记录分类变量的特殊类型，参照组决定类别回归系数的解释方式。

### 代码 01｜水平-水平线性模型：mpg对车辆重量wt

**原讲义位置**：线性模型。

**这段想做什么？**

以mtcars数据集建立原始尺度的线性关系，作为之后两种对数模型的对照。

**课堂原始R代码（完整保留）**

```r
mtcars %>% lm(mpg ~ wt, data=.) %>% summary
```

**逐行讲解**

1. **第1行** `mtcars %>% lm(mpg ~ wt, data=.) %>% summary`：从R内置`mtcars`汽车数据框开始管道流程。 出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `data=.`中的`.`是管道传来的数据，**不是小数点或缺失值**。 `~`连接分析公式两侧；这一段说明了结果变量和解释变量/分组变量之间的关系。 `lm()`拟合线性回归，括号内包括公式与数据来源。 `summary()`输出摘要；模型对象包括估计系数、标准误、t值、p值等。

**把函数和统计概念拆开看**

1. `mtcars`是R自带数据集，不需要先加载LFS文件。
2. `lm(mpg ~ wt, data=.)`预测燃油经济性mpg随车辆重量wt的线性变化。
3. `%>% summary`在R管道中传递模型给`summary()`方法；虽然末尾没有括号，作为右侧函数在magrittr管道中可成立。
4. 系数`wt`表示重量每增加1个mtcars重量单位（1000磅），预测mpg变化的数值。

### 代码 02｜半对数模型：对因变量mpg取自然对数

**原讲义位置**：半对数模型。

**这段想做什么？**

保持wt原尺度，只对mpg取对数，观察函数形式改变如何影响拟合。

**课堂原始R代码（完整保留）**

```r
mtcars %>% mutate(log_mpg = log(mpg)) %>% lm(log_mpg ~ wt, data=.) %>% summary
```

**逐行讲解**

1. **第1行** `mtcars %>% mutate(log_mpg = log(mpg)) %>% lm(log_mpg ~ wt, data=.) %>% summary`：从R内置`mtcars`汽车数据框开始管道流程。 出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `data=.`中的`.`是管道传来的数据，**不是小数点或缺失值**。 `~`连接分析公式两侧；这一段说明了结果变量和解释变量/分组变量之间的关系。 `lm()`拟合线性回归，括号内包括公式与数据来源。 `summary()`输出摘要；模型对象包括估计系数、标准误、t值、p值等。 `mutate()`创建新数据列或覆盖现有列。 `log()`默认取自然对数；必须注意输入是否为0或负数。

**把函数和统计概念拆开看**

1. `mutate(log_mpg = log(mpg))`创建新列log_mpg；原数据集mtcars本身未被永久修改，因为没有赋值回去。
2. `log()`默认是自然对数（底数e），要求输入大于0。
3. `lm(log_mpg ~ wt, data=.)`解释的是**对数后的**mpg，而不是原始mpg。
4. 在半对数模型中，wt系数乘以100可近似理解为wt每增加1单位时mpg的百分比变化；更精确用`100*(exp(β)-1)`。

回归摘要读法：`Call`说明实际模型公式；`Coefficients`中`Estimate`是系数、`Std. Error`是标准误、`t value`是估计/标准误、`Pr(>|t|)`为显著性检验；`Multiple R-squared`是模型在当前因变量尺度下的解释比例。

### 代码 03｜双对数模型：mpg和wt都取自然对数

**原讲义位置**：双对数模型。

**这段想做什么？**

把两侧变量都换到对数尺度，得到常称为log-log的模型。

**课堂原始R代码（完整保留）**

```r
mtcars %>% mutate(log_mpg = log(mpg), log_wt = log(wt)) %>% lm(log_mpg ~ log_wt, data=.) %>% summary
```

**逐行讲解**

1. **第1行** `mtcars %>% mutate(log_mpg = log(mpg), log_wt = log(wt)) %>% lm(log_mpg ~ log_wt, data=.) %>% summary`：从R内置`mtcars`汽车数据框开始管道流程。 出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `data=.`中的`.`是管道传来的数据，**不是小数点或缺失值**。 `~`连接分析公式两侧；这一段说明了结果变量和解释变量/分组变量之间的关系。 `lm()`拟合线性回归，括号内包括公式与数据来源。 `summary()`输出摘要；模型对象包括估计系数、标准误、t值、p值等。 `mutate()`创建新数据列或覆盖现有列。 `log()`默认取自然对数；必须注意输入是否为0或负数。

**把函数和统计概念拆开看**

1. `mutate(log_mpg = log(mpg), log_wt = log(wt))`一次创建两列。
2. `lm(log_mpg ~ log_wt)`回归对数mpg对对数重量。
3. `log_wt`的斜率可以被理解为近似弹性：重量变动1%，mpg平均约变动β%。
4. 对数解释不能用于零值、负值；需要先理解数据编码。

## 三、按课堂顺序串起来：这一讲完整分析流程

### 三类回归形式（逐个变量理解）
1. **水平—水平（level-level）**：`y ~ x`。β表示x增加1单位时，y的预测值变化β个**原单位**。
2. **对数—水平（log-level）**：`log(y) ~ x`。x增加1单位，y的比例变化精确为`exp(β)-1`，百分比为`100*(exp(β)-1)`；β较小时约为`100*β%`。
3. **对数—对数（log-log）**：`log(y) ~ log(x)`。β是局部弹性：x增加约1%，y变化约β%。
4. **R²不可跨不同因变量尺度直接比大小**：模型解释`y`还是`log(y)`，总变异不同。
5. **检验问题不同**：`resettest()`找某些设定偏误；`bptest()`检验残差异方差；`plot(which=2)`观察正态分位数偏离。三者不能互相代替。
6. **对数定义域**：`log(0)=-Inf`，负数取log在实数范围无定义。正式清洗时要记录删去或重新定义的样本，不要偷偷用`log(y+1)`改变研究对象。

### 需要记住的完整逻辑

1. 先比较汽车数据的三种尺度：原始、半对数、双对数。
2. 通过残差图了解为何一种函数形式可能更符合数据。
3. 用RESET检查设定问题，使用BP检验异方差。

## 六、初学者常见错误与排查顺序

1. **object not found（对象不存在）**：确认是否先创建了`lfs`或`fake_data`，或前一步的`select()`是否把变量删掉。
2. **could not find function（找不到函数）**：确认是否安装并`library()`了相应包。
3. **unexpected symbol / unexpected end of input（语法错误）**：检查括号、引号、逗号和前一行末尾的`%>%`是否完整。
4. **missing values / NA / -Inf**：统计函数遇到`NA`或`log(0)`会出问题，正式分析需遵循数据字典及清洗记录。
5. **contrasts can be applied only to factors with 2 or more levels**：筛选样本后某个分类变量可能只剩一类，需要检查`table()`或`levels()`。
6. **课程输出与自己不同**：先比较数据版本、样本行数、变量类型、参考组、缺失处理和包版本，不要立即修改统计模型去“凑数”。
7. **统计显著误当成因果关系**：观察数据中的关联仍可能受未观测因素影响，报告必须诚实描述限制。
