### 1.2 把R代码当成一句完整的话来阅读

| 写法 | 初学者的读法 | 常见误解 |
|---|---|---|
| `x <- ...` | 把右边结果保存到x | 以为`<-`是小于号 |
| `f(x, y)` | 调用函数f，把x和y作为参数 | 以为所有括号都在做数学乘法 |
| `data = lfs` | 指定数据对象 | 以为这里是把变量赋值给lfs |
| `df$AGE` | 从df里抽取AGE这一列 | 以为`$`有货币意义 |
| `a %>% b()` | 先做a，再把结果交给b | 与ggplot的图层加号`+`混淆 |
| `y ~ x1 + x2` | 用x1、x2共同解释y | 把公式中的`+`当成数值求和 |
| `"Female"` | 这是**字符串文字** | 误以为是变量名 |
| `TRUE`与`FALSE` | 布尔值/逻辑值 | 与文字`"TRUE"`混淆 |
| `# ...` | 注释，对运行结果无影响 | 把注释当成一定会运行的代码 |
| `<`、`==` | 分别表示小于、是否相等 | 把`==`与赋值符混淆 |

如果一行很长，先找最外层函数，再拆成“传入的数据→做了什么→返回什么”；碰到多层括号，从**最里面的函数**开始理解。

### 1.5 这几类对象是什么？
- **向量（vector）**：一列同类型值，常由`c(...)`生成。
- **数据框（data.frame / tibble）**：像Excel表格，行对应观测、列对应变量。
- **函数（function）**：执行特定任务，如`mean()`求平均、`lm()`拟合回归。
- **参数（argument）**：括号里告诉函数如何工作的选项，例如`data = lfs`。
- **模型对象**：`lm(...)`运行后返回的结果，里面有系数、残差、拟合值等，不只是一个单独数字。
- **因子（factor）**：R记录分类变量的特殊类型，参照组决定类别回归系数的解释方式。

### 代码 01｜以最高资格类别预测小时工资：分类解释变量回归

**原讲义位置**：线性回归模型。

**这段想做什么？**

查看不同教育资格组的平均小时工资差异，理解“参考组”决定了系数相对谁比较。

**课堂原始R代码（完整保留）**

```r
lm(HOURPAY ~ HIQUL22D, data = lfs) %>% summary()
```

**逐行讲解**

1. **第1行** `lm(HOURPAY ~ HIQUL22D, data = lfs) %>% summary()`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `data=lfs`明确指定从lfs表取变量。 `~`连接分析公式两侧；这一段说明了结果变量和解释变量/分组变量之间的关系。 `lm()`拟合线性回归，括号内包括公式与数据来源。 `summary()`输出摘要；模型对象包括估计系数、标准误、t值、p值等。

**把函数和统计概念拆开看**

1. `HIQUL22D`是分类变量时，`lm()`会为除基准类别之外的各类别建立比较系数。
2. `(Intercept)`代表基准类别的平均工资预测值。
3. 每一个学历系数代表相对基准类别的差额，而不是该组工资本身。
4. 必须使用`levels(lfs$HIQUL22D)`确认实际参照组；课程正文以拥有学位的人作为示例参照类别。

### 代码 02｜用单因素方差分析检验资格类别的整体工资差异

**原讲义位置**：F检验。

**这段想做什么？**

把工资总变异划分为组间变异和组内变异，以F统计量检验各组总体均值是否相同。

**课堂原始R代码（完整保留）**

```r

**原讲义位置**：在R中计算相关系数。

**这段想做什么？**

```

**逐行讲解**

3. `cor(x,y)`默认计算Pearson相关系数，度量**线性关联**而非因果影响。

### 代码 04｜用cor.test检验相关系数是否显著：向量写法

**原讲义位置**：检验统计显著性。

**这段想做什么？**

在上一段相关系数之外，同时报告检验统计量、置信区间与p值。

**课堂原始R代码（完整保留）**

```r
cor.test(lfs$HOURPAY, lfs$AGE)
```

**逐行讲解**

1. **第1行** `cor.test(lfs$HOURPAY, lfs$AGE)`：`cor.test()`不只计算r，还提供t统计量、置信区间和p值。

**把函数和统计概念拆开看**

1. `cor.test(x,y)`检验总体相关系数是否为0。
2. 默认`method = "pearson"`，可在其他情境根据研究问题考虑Spearman等方法。
3. 输出中的`t`和`df`来自相关检验的统计量与自由度。
4. `95 percent confidence interval`是总体相关系数的区间估计，不应误认为95%的样本位于该区间。

**课件输出怎样读？**

下面是从**原HTML控制台输出中摘取的关键行**（不是重新计算的结果；完整输出仍在原课件）：

```text

##  Pearson's product-moment correlation
## 
## data:  lfs$HOURPAY and lfs$AGE
## t = 11.901, df = 7345, p-value < 2.2e-16
## alternative hypothesis: true correlation is not equal to 0
## 95 percent confidence interval:
##  0.1150412 0.1599101

##       cor

```

`cor`表示样本Pearson相关系数，`p-value`检验总体相关是否为零，`confidence interval`反映估计不确定性。这三个量回答不同问题。

**初学者容易踩的坑／研究上的注意事项**

讲义报告`p-value < 2.2e-16`，意味着“零相关”的原假设很难解释观测数据；但0.1375仍是小的相关系数：**统计显著不等于关系强**。

### 代码 06｜用年龄预测小时工资的一元线性回归

**原讲义位置**：线性模型。

**这段想做什么？**

学习连续自变量的回归系数如何解释：年龄每增加1单位，平均预测工资变化多少。

**课堂原始R代码（完整保留）**

```r
lm(HOURPAY ~ AGE, data=lfs) %>% summary()
```

**逐行讲解**

1. **第1行** `lm(HOURPAY ~ AGE, data=lfs) %>% summary()`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `data=lfs`明确指定从lfs表取变量。 `~`连接分析公式两侧；这一段说明了结果变量和解释变量/分组变量之间的关系。 `lm()`拟合线性回归，括号内包括公式与数据来源。 `summary()`输出摘要；模型对象包括估计系数、标准误、t值、p值等。

**把函数和统计概念拆开看**

1. `AGE`是数值变量时，`lm(HOURPAY ~ AGE)`拟合一条直线。
2. 截距表示AGE为0时的数学预测值，可能不属于样本年龄范围，不应作现实解释。
3. `AGE`的系数是工资对年龄的线性斜率，其单位为工资单位/岁。

## 三、按课堂顺序串起来：这一讲完整分析流程

### 三种问题，三种分析
- **ANOVA**：分类变量将人分成多组（例如学历），总体均值是否至少有一组不同？重点看F检验。
- **相关**：两个数值变量（例如年龄、工资）一起变化的线性方向和强度如何？重点看r及其区间。
- **回归**：当x变化一单位，y的线性预测均值变化多少？重点看回归系数、标准误、显著性和模型假设。
- **参照组**：类别变量回归系数通常相对于某个基准类。换参照组会改变系数显示方式，不会凭空创造新信息。
- **样本显著 vs 实质重要**：大量数据能检出很小的关系；研究问题仍要解释实际效应有多大。

### 需要记住的完整逻辑

1. 用分类回归查看各学历组相对基准组的工资差。
2. 用ANOVA的**整体F检验**判断各组总体均值是否完全相同。
3. 用`cor()`定量描述年龄和工资的线性关联。
4. 用`cor.test()`检验相关系数。
5. 用`lm(HOURPAY ~ AGE)`转化为可解释的年龄斜率。

## 六、初学者常见错误与排查顺序

1. **object not found（对象不存在）**：确认是否先创建了`lfs`或`fake_data`，或前一步的`select()`是否把变量删掉。
2. **could not find function（找不到函数）**：确认是否安装并`library()`了相应包。
3. **unexpected symbol / unexpected end of input（语法错误）**：检查括号、引号、逗号和前一行末尾的`%>%`是否完整。
4. **missing values / NA / -Inf**：统计函数遇到`NA`或`log(0)`会出问题，正式分析需遵循数据字典及清洗记录。
5. **contrasts can be applied only to factors with 2 or more levels**：筛选样本后某个分类变量可能只剩一类，需要检查`table()`或`levels()`。
6. **课程输出与自己不同**：先比较数据版本、样本行数、变量类型、参考组、缺失处理和包版本，不要立即修改统计模型去“凑数”。
7. **统计显著误当成因果关系**：观察数据中的关联仍可能受未观测因素影响，报告必须诚实描述限制。
