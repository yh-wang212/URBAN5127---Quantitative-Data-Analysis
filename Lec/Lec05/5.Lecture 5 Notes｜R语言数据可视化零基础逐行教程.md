## 0. 完全零基础先了解的内容

### 0.1 对象、列和函数

- `lfs` 是存储整个数据集的**数据框**（data frame/tibble），像一个带很多行列的Excel表。
- `AGE`、`SEX`、`HOURPAY` 等是**列名**。大小写要严格一致。
- `ggplot(...)`、`geom_boxplot(...)` 是**函数**，括号中可以指定**参数**。
- `=` 在函数中通常指定参数值；在 `mutate(new_column = ...)` 中则指定新列名和计算内容。
- `"Hourly wage (£)"` 是字符串/文字；`HOURPAY` 不加引号表示数据列。
- `TRUE` 是逻辑真；`0.2` 是数字；`~` 是分面公式语法的一部分。

### 0.2 需要加载哪些包？

课堂代码使用 `%>%`、`ggplot()`、`fct_reorder()`、`fct_infreq()` 和 `scale_fill_colorblind()`。这些函数来自 tidyverse 各子包以及 ggthemes。首次安装包可运行：

```r
install.packages("tidyverse")
install.packages("ggthemes")
```

安装通常只需做一次。每次重新启动R会话后可运行：

```r
library(tidyverse)
```

`library(ggthemes)` 在讲义第18段中单独出现；如要提前运行第18、19段，也可以预先加载。确认 `lfs` 已读取，且 `SEX`、`HOURPAY` 等列存在。如何读取文件取决于你的本地文件路径及教师提供的数据处理过程，讲义这19段从**已经存在的 `lfs` 对象**开始，而不是从导入数据开始。

### 0.3 两种“连接符”极容易混淆

```r
lfs %>%
  ggplot(aes(AGE, HOURPAY)) +
  geom_point()
```

`%>%` 将**数据传给函数**：从 lfs 到 ggplot。`+` 是 **ggplot 图层相加**：将点图层叠加到已建立的图上。它们不能简单互换。

### 0.4 为什么工资图需要留意对数尺度？

`scale_y_log10()` 或 `scale_x_log10()` 让坐标按10倍数量级展示，有助于观察高度偏斜的工资分布；这不代表工资单位变成了对数英镑。严格来说，非正工资不能进行 log10 变换；绘图警告需检查。要判断极端值是否为有效收入、数据特殊编码还是错误，必须参考数据字典。

## 1. 性别与小时工资：第一个箱线图

**本段目标**：这一段是本讲的起点：用箱线图比较不同性别组的工资。先掌握横轴分组、纵轴数值和对数坐标。

### 课堂原始代码（保持不变）

```r
lfs %>%
  ggplot(aes(SEX, HOURPAY)) + 
  geom_boxplot() +
  theme_minimal() +
  scale_y_log10() +
  labs(title = "Distribution of hourly wage by sex",
     subtitle = "Logarithmic scale",
     x = "Sex",
     y = "Hourly wage (£)",
     caption = "Source: Quarterly Labour Force Survey - January-March 2025") +
  theme(legend.title = element_blank())
```

### 从第一行开始理解

**第 1 行：** `lfs %>%`  
从数据框 `lfs` 开始；`%>%` 把它送往下一步。 末尾 `%>%` 表示继续将数据传到下一步。

**第 2 行：** `ggplot(aes(SEX, HOURPAY)) +`  
开始建立图对象。`aes(...)` 指定横轴、纵轴或填色变量；仅有 ggplot 初始化时可能还没有几何图形。 末尾 `+` 表示后面还要接一个 ggplot 图层或样式。

**第 3 行：** `geom_boxplot() +`  
添加箱线图层，呈现中位数、四分位距等。 末尾 `+` 表示后面还要接一个 ggplot 图层或样式。

**第 4 行：** `theme_minimal() +`  
使用简洁的预设图形主题。 末尾 `+` 表示后面还要接一个 ggplot 图层或样式。

**第 5 行：** `scale_y_log10() +`  
使用底数为10的纵轴对数刻度；非正值不能直接取 log10。 末尾 `+` 表示后面还要接一个 ggplot 图层或样式。

**第 6 行：** `labs(title = "Distribution of hourly wage by sex",`  
添加图形标题、轴标题、图例标题和来源说明等。

**第 7 行：** `subtitle = "Logarithmic scale",`  
这一项是图表显示的标题/副标题/来源说明，是一段**文字字符串**，并非统计变量。

**第 8 行：** `x = "Sex",`  
设置横轴或纵轴显示名称；`""` 表示故意留空，不显示轴标题。

**第 9 行：** `y = "Hourly wage (£)",`  
设置横轴或纵轴显示名称；`""` 表示故意留空，不显示轴标题。

**第 10 行：** `caption = "Source: Quarterly Labour Force Survey - January-March 2025") +`  
这行给图添加数据来源说明。 末尾 `+` 表示后面还要接一个 ggplot 图层或样式。

**第 11 行：** `theme(legend.title = element_blank())`  
调整图例、轴文字等非数据层的图形外观。 去除特定图形元素，例如图例标题。

| 名称 | 含义 |
|---|---|

### 图应该怎样读？为什么这样画？

箱体下缘通常是 Q1，上缘通常是 Q3；箱内线是中位数。箱须和离群点的规则由 geom_boxplot() 的统计变换决定，不能认为箱须必然等于最小值和最大值。

**动手练习**：先原样运行该段，再有意识地只调整一个显示参数（例如标题、透明度、`coord_flip()` 是否添加），观察可视化有何变化；不要同时改动多个地方，否则很难判断是哪一项导致结果改变。

## 20. 第五讲所有代码的总体逻辑

| 目标 | 课堂方法 | 阅读重点 |
|---|---|---|
| 比较连续变量在类别组内的分布 | `geom_boxplot()` | 中位数、Q1、Q3、箱须、离群点 |
| 展示各类别的分布轮廓 | `geom_violin()` | 核密度形状与宽度 |
| 显示大量单条记录 | `geom_jitter()` | 重叠、透明度、抖动 |
| 探索两个连续变量关系 | `geom_point()` | 散点模式，不代表因果 |
| 拆分多个对比面板 | `facet_wrap()`、`facet_grid()` | 单变量或双变量分面 |
| 显示类别组合的数值 | `group_by()` → `summarise()` → `geom_tile()` | 先汇总再映射填色 |
| 统计类别频数 | `geom_bar()` | 默认样本记录数量 |
| 比较数量构成 | `geom_bar(aes(fill=...))` | 堆叠数量 |
| 比较内部份额 | `geom_bar(position="fill")` | 100%构成而非总量 |

## 21. 八组极容易混淆的概念

### 21.1 `geom_boxplot()` 与 `geom_violin()`

箱线图强调分位数、中位数、离群点；小提琴图强调经平滑估计的分布形状。两种图可以叠加，前提是数据和分组映射一致。

### 21.2 `geom_point()` 与 `geom_jitter()`

前者按真实数值坐标绘点；后者人为加入少量位置扰动，避免大量观测堆在同一点。抖动是绘图技巧，不应该把微小偏移解读成真实的个体差异。

### 21.3 `aes(fill = SEX)` 与 `fill = "blue"`

前者由每条记录的性别组决定颜色、通常会出现图例；后者是给图层统一指定蓝色，不涉及一个用来分类的变量。

### 21.4 `scale_y_log10()` 与 `scale_x_log10()`

注意选的是哪个轴；`coord_flip()` 还会影响图表最后的可视位置。数值为零或负数不能直接做 log10。

### 21.5 `facet_wrap(~GOR9D)` 与 `facet_grid(FTPT~JOBTYP)`

`facet_wrap` 用单个变量铺设很多面板；`facet_grid` 的 `~` 左侧指定行、右侧指定列。

### 21.6 `group_by()` 与 `summarise()`

分组只是告诉R“每一组包含什么”；真正计算一组一个平均值的是 `summarise()`。缺任何一个，后续热力图可能无法表达各组的平均工资。

### 21.7 `geom_bar()` 计数与 `geom_bar(position="fill")` 份额

计数图的柱高是样本行数；`position="fill"` 将每根柱转换成组内的相对构成。**两者回答不同问题**：哪组记录多 vs 某组内部各类别占比多少。

### 21.8 `fct_reorder()` 与 `fct_infreq()`

`fct_reorder()` 按另一列的统计量（本讲是小时工资的 `median`）给分类排序；`fct_infreq()` 按分类出现次数排序；`fct_rev()` 则把已有顺序倒过来。

## 22. 零基础常见报错与处理

**错误一：`could not find function "ggplot"`**  
原因：没加载相应包。先安装 tidyverse，再运行 `library(tidyverse)`。

**错误二：`object 'lfs' not found`**  
原因：数据没有成功读取到对象 `lfs`，或重新打开 R 后丢失了上一次会话对象。

**错误三：`object 'HOURPAY' not found`**  
原因：列名不同、数据读入错误、大小写不同，或当前传入的不是包含该列的数据框。先运行 `names(lfs)` 检查。

**错误四：找不到 `fct_reorder` 或 `fct_infreq`**  
它们来自 forcats；一般加载 `tidyverse` 即可，也可用 `forcats::fct_reorder(...)` 明确指定包。

**错误五：找不到 `scale_fill_colorblind`**  
它来自 `ggthemes`；先 `install.packages("ggthemes")`，然后 `library(ggthemes)`。

**错误六：`Removed ... rows` / `Transformation introduced infinite values`**  
可能有缺失值、无效记录或不能取对数的非正数。先检查 `summary(lfs$HOURPAY)` 和工资变量的编码。不能只为了“消除警告”而随意删除数据。

**错误七：热力图出现 NA 色块**  
原课件的 `mean(HOURPAY)` 默认不跳过 NA。在理解数据质量后，若适当，可考虑 `mean(HOURPAY, na.rm = TRUE)`；还应确保一个组并非全部缺失。

**错误八：图例和轴标题位置不符合预期**  
`labs(fill="...")` 改填色图例的标题；`theme(legend.title=element_blank())` 隐藏它；`theme(legend.position="top")` 改变图例位置。作用各不相同。

## 23. 研究解释中的必要提醒（额外补充，不是课堂原代码）

- `lfs` 是复杂抽样调查微观数据。本讲绘图代码旨在学习 ggplot2 绘图，**并未显式应用劳动力调查权重**；不能将简单样本频数直接解释为英国总人口或总体就业人数。
- `mean(HOURPAY)` 是普通算术平均；若研究目标是具有总体代表性的收入估计，需要讨论调查权重、样本选择及官方推荐的估计方法。
- 性别、行业、教育等分类变量的确切数值编码必须以数据字典为准。讲义中表现为文本标签时，先核对因子水平，再进行解释。
- 相关与差异不等于因果。不同性别/教育/行业的工资差异可能与年龄、经验、工作时间、职业等共同相关。
