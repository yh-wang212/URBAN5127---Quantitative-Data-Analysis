### 1.1 R / RStudio到底是什么？
R是一种用于统计分析的编程语言；RStudio是帮助你编辑、运行、检查R程序的工作界面。**R语言**决定代码含义，**RStudio**提供Source（脚本编辑器）、Console（即时运行）、Environment（查看对象）、Plots（看图）等窗口。

### 1.2 把R代码当成一句完整的话来阅读

| 写法 | 初学者的读法 | 常见误解 |
|---|---|---|
| `x <- ...` | 把右边结果保存到x | 以为`<-`是小于号 |
| `f(x, y)` | 调用函数f，把x和y作为参数 | 以为所有括号都在做数学乘法 |
| `data = lfs` | 指定数据对象 | 以为这里是把变量赋值给lfs |
| `df$AGE` | 从df里抽取AGE这一列 | 以为`$`有货币意义 |
| `a %>% b()` | 先做a，再把结果交给b | 与ggplot的图层加号`+`混淆 |
| `y ~ x1 + x2` | 用x1、x2共同解释y | 把公式中的`+`当成数值求和 |
| `"Female"` | 这是**字符串文字** | 误以为是变量名 |
| `TRUE`与`FALSE` | 布尔值/逻辑值 | 与文字`"TRUE"`混淆 |
| `# ...` | 注释，对运行结果无影响 | 把注释当成一定会运行的代码 |
| `<`、`==` | 分别表示小于、是否相等 | 把`==`与赋值符混淆 |

如果一行很长，先找最外层函数，再拆成“传入的数据→做了什么→返回什么”；碰到多层括号，从**最里面的函数**开始理解。

### 1.5 这几类对象是什么？
- **向量（vector）**：一列同类型值，常由`c(...)`生成。
- **数据框（data.frame / tibble）**：像Excel表格，行对应观测、列对应变量。
- **函数（function）**：执行特定任务，如`mean()`求平均、`lm()`拟合回归。
- **参数（argument）**：括号里告诉函数如何工作的选项，例如`data = lfs`。
- **模型对象**：`lm(...)`运行后返回的结果，里面有系数、残差、拟合值等，不只是一个单独数字。
- **因子（factor）**：R记录分类变量的特殊类型，参照组决定类别回归系数的解释方式。

### 代码 01｜估计多元工资模型的广义方差膨胀因子GVIF

**原讲义位置**：模型的VIF值。

**这段想做什么？**

通过car包的`vif()`检查多个解释变量是否存在较严重的线性相关性问题。

**课堂原始R代码（完整保留）**

```r
lfs %>% mutate(log_wage = log(HOURPAY)) %>% 
  lm(log_wage ~ SEX + AGE + HIQUL22D + FLEX22W6 + FTPT + EMPLEN + JOBTYP + MPNR02 + MARSTA + INDE07M + NSECMJ20 + GOR9D, 
     data=.) %>% 
 vif()
```

**逐行讲解**

1. **第1行** `lfs %>% mutate(log_wage = log(HOURPAY)) %>%`：从`lfs`数据框开始进入管道流程。 出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `mutate()`创建新数据列或覆盖现有列。 `log()`默认取自然对数；必须注意输入是否为0或负数。
2. **第2行** `lm(log_wage ~ SEX + AGE + HIQUL22D + FLEX22W6 + FTPT + EMPLEN + JOBTYP + MPNR02 + MARSTA + INDE07M + NSECMJ20 + GOR9D,`：`~`连接分析公式两侧；这一段说明了结果变量和解释变量/分组变量之间的关系。 公式中的`+`表示**同时纳入**这些解释变量，并非对列做逐行算术加法。 `lm()`拟合线性回归，括号内包括公式与数据来源。
3. **第3行** `data=.) %>%`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `data=.`中的`.`是管道传来的数据，**不是小数点或缺失值**。
4. **第4行** `vif()`：`vif()`计算（广义）方差膨胀因子，检视解释变量共线性。

**把函数和统计概念拆开看**

1. `mutate(log_wage = log(HOURPAY))`建立对数工资。
2. `lm(...)`拟合包括性别、年龄、教育、地区等的多元线性回归。
3. `vif()`来自`car`包，对连续项通常显示VIF，对多自由度分类项往往显示GVIF及调整指标。
4. `GVIF^(1/(2*Df))`用于对不同自由度的因子项进行尺度调整；不能直接把原始GVIF与简单VIF的阈值机械比较。

### 代码 08｜把婚姻状况重编码成更少类别

**原讲义位置**：创建新变量。

**这段想做什么？**

**课堂原始R代码（完整保留）**

```r

  mutate(new_MARSTA = case_when(
    MARSTA == "Married, living with spouse" ~ "Married",
    MARSTA == "Divorced" ~ "Divorced",

      factor() %>%

    )
```

**逐行讲解**

1. **第1行** `lfs <- lfs %>%`：赋值：用`<-`将右侧结果保存到`lfs`。 出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。
2. **第2行** `mutate(new_MARSTA = case_when(`：`mutate()`创建新数据列或覆盖现有列。 `case_when()`按条件顺序给每行数据指定新类别。 `new_MARSTA`是前面重编码后的婚姻状况，执行前要确认它已存在。
3. **第3行** `MARSTA == "Married, living with spouse" ~ "Married",`：`==`判断原始婚姻状态是否**等于**某一标签，`~`右侧是满足条件时的输出标签。

5. **第5行** `TRUE ~ "Other") %>%`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `TRUE ~ "Other"`兜底：没有匹配前面条件的观测将标为Other。
6. **第6行** `factor() %>%`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `factor()`将文字类别转换为R的因子类型。
7. **第7行** `relevel(ref = "Other")`：`relevel()`将指定因子水平设为参考类别，影响回归系数相对谁计算。
8. **第8行** `)`：本行继续或结束上一行的函数参数/括号；R通过括号判断完整表达式。

**把函数和统计概念拆开看**

1. `lfs <- lfs %>%`会把处理后的数据框**赋值回**lfs（真正改变当前对象）。
2. `case_when()`按条件从上往下匹配，输出字符串“Married”“Divorced”“Other”。

4. `TRUE ~ "Other"`是兜底分支，匹配之前所有未符合条件的行，包括可能需要另行核查的缺失或未知编码。

### 代码 12｜计算异方差稳健标准误并重新进行系数检验

**原讲义位置**：稳健标准误。

**这段想做什么？**

用lmtest的`coeftest()`和sandwich的`vcovHC()`，保持原回归系数、更新标准误和t检验。

**课堂原始R代码（完整保留）**

```r
lfs %>% 
  mutate(log_wage = log(HOURPAY)) %>%
  lm(log_wage ~ SEX + AGES + HIQUL22D + FTPT + JOBTYP + MPNR02 + new_MARSTA + INDE07M + NSECMJ20 + GOR9D, data=.) %>%
coeftest(., vcov = vcovHC(.))
```

**逐行讲解**

1. **第1行** `lfs %>%`：从`lfs`数据框开始进入管道流程。 出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。
2. **第2行** `mutate(log_wage = log(HOURPAY)) %>%`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `mutate()`创建新数据列或覆盖现有列。 `log()`默认取自然对数；必须注意输入是否为0或负数。
3. **第3行** `lm(log_wage ~ SEX + AGES + HIQUL22D + FTPT + JOBTYP + MPNR02 + new_MARSTA + INDE07M + NSECMJ20 + GOR9D, data=.) %>%`：出现`%>%`：右侧操作接收左侧结果，下一步仍沿这条流程继续。 `data=.`中的`.`是管道传来的数据，**不是小数点或缺失值**。 `~`连接分析公式两侧；这一段说明了结果变量和解释变量/分组变量之间的关系。 公式中的`+`表示**同时纳入**这些解释变量，并非对列做逐行算术加法。 `lm()`拟合线性回归，括号内包括公式与数据来源。 `AGES`是年龄分组变量，不应与连续年龄`AGE`等同。 `new_MARSTA`是前面重编码后的婚姻状况，执行前要确认它已存在。
4. **第4行** `coeftest(., vcov = vcovHC(.))`：`coeftest()`列出系数估计及依据指定协方差矩阵计算的检验结果。 `vcovHC(.)`依据当前模型计算异方差稳健系数协方差矩阵。

**把函数和统计概念拆开看**

1. `coeftest()`接受拟合好的模型对象，并重新计算系数检验。
2. `vcovHC(.)`基于管道传入的模型计算异方差稳健的协方差矩阵；点号指该模型。
3. `vcov = vcovHC(.)`用新的方差协方差矩阵替代默认估计，以更新Std. Error、t值和p值。
4. 稳健标准误通常不改变OLS系数点估计值（Estimate），但可改变显著性判断。

## 三、按课堂顺序串起来：这一讲完整分析流程

### “模型变好”要分清三件不同的事
- **识别问题**：VIF/GVIF检验解释变量间的冗余程度；RESET检验设定；BP检验异方差；这些指标回答的问题不同。
- **改变模型**：移除`EMPLEN`、将年龄从`AGE`改为`AGES`、重编码婚姻变量、重新设置行业参照组；这些操作改变了研究假设和系数含义，应逐项记录依据。
- **改变推断方式**：`coeftest(..., vcov = vcovHC(...))`在同一OLS系数上采用另一种标准误估计方式；不等于重新拟合一个能解决所有偏误的模型。
- **敏感性比较**：每改一次模型，记录样本量、变量集合、拟合形式、关键系数、标准误、诊断检验以及选择理由。
- **注意讲义内表述与代码的差异**：重新编码婚姻状态的代码产生三组，而不是讲解文字口头提及的两组。

### 需要记住的完整逻辑

1. 用GVIF查看变量间冗余。
2. 对原始模型、半对数模型、删减模型分别进行RESET/BP检验。
3. 重编码婚姻状态、调整行业参照组、调整年龄表示和解释变量。
4. 对修改后的OLS回归采用异方差稳健标准误，不把它误当成重构因果模型。

## 六、初学者常见错误与排查顺序

1. **object not found（对象不存在）**：确认是否先创建了`lfs`或`fake_data`，或前一步的`select()`是否把变量删掉。
2. **could not find function（找不到函数）**：确认是否安装并`library()`了相应包。
3. **unexpected symbol / unexpected end of input（语法错误）**：检查括号、引号、逗号和前一行末尾的`%>%`是否完整。
4. **missing values / NA / -Inf**：统计函数遇到`NA`或`log(0)`会出问题，正式分析需遵循数据字典及清洗记录。
5. **contrasts can be applied only to factors with 2 or more levels**：筛选样本后某个分类变量可能只剩一类，需要检查`table()`或`levels()`。
6. **课程输出与自己不同**：先比较数据版本、样本行数、变量类型、参考组、缺失处理和包版本，不要立即修改统计模型去“凑数”。
7. **统计显著误当成因果关系**：观察数据中的关联仍可能受未观测因素影响，报告必须诚实描述限制。
